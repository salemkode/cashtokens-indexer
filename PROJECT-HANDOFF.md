## Historical context — translated snapshot, 15 November 2026

The project began as a request for a CashTokens indexer inspired by SLP Indexer,
for integration with `salemkode/explorer`. The user clarified that the target is
one server using BCHN directly and storing only the missing specialized state,
rather than rebuilding Chaingraph or duplicating all BCH transactions in tables.

BCHN is the source of truth for blocks, transactions and mempool data. The
specialized index covers categories, token UTXOs, supply, holders, NFTs, history
and burns. Electrum remains the address-history source. The original explorer is
the requirements/acceptance workload; its features must not be removed to conceal
backend gaps.

integer quantities, atomic indexing, reorg rollback and an explorer integration

statistics, repeated block decoding and permanently retained spent outputs.

outstanding at that snapshot. Historical microbenchmarks were synthetic and did
not establish production superiority or a VPS size. The organization/migration
pass did not rerun product tests or authorize deployment.

The target remains an explorer with its required features on BCHN and limited
indexes, with documented boundaries and measurements. Project files are real
